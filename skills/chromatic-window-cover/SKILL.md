# Chromatic Window Cover

Transform the supplied photograph into one contemporary magazine cover. The result should feel decisive and graphic while the subject remains recognizably the same.

## Core language

- Default to a vertical 3:4 cover.
- Use one primary photographic window and, optionally, one narrow secondary window cut from the same source.
- Build a palette of one dominant field color, one dark ink color, and one light neutral. Derive the dominant color from the source image, then adjust it for clear contrast.
- Use flat, precise geometry: rectangles, bands, circles, or a single oversized letterform. Limit the composition to two geometric devices.
- Keep edges machine-cut and clean. Avoid paper tears, fibers, vintage distress, scrapbook layering, and imitation print damage.
- Use a modern display face for the masthead and a quiet sans serif for supporting text.

## Cover strategy

Inspect the photograph for its strongest silhouette, gaze, directional line, and area of visual calm. Choose one arrangement: an offset window, an edge crop, or a split register with one narrow repeated source crop. Select the arrangement that preserves the subject with the least distortion. Do not combine all three.

## Typography

- Create a short masthead of 2–8 characters or 1–3 words. Use supplied text when available; otherwise use a neutral editorial word related to the visible scene.
- Add at most two supporting lines.
- Never invent claims, prices, dates, issue numbers, locations, artist names, or affiliations.
- Typography may overlap a quiet area but must not cover a face, key object, logo, or meaningful source text.
- Keep all text horizontal unless the user explicitly requests vertical type.

## Image integrity

- Preserve identity, anatomy, product geometry, architecture, landscape structure, and existing text.
- Do not restyle the photograph as an illustration.
- Do not insert props, wardrobe, makeup, buildings, vehicles, vegetation, or atmospheric effects.
- Allow only restrained tonal correction and source-faithful cropping.
- If the source lacks safe negative space, reduce the masthead instead of generating new background content.

## Final criteria

The cover must have one obvious focal point, one dominant color decision, readable typography, and a photographic subject that still matches the source. Remove any element that does not improve hierarchy.

Return the finished image only unless the user asks for a rationale.
