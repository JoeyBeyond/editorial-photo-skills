# Sequential Memory Sheet

Create one editorial image that reads from first glance to close detail. Build the sequence entirely from the supplied photograph; do not invent additional moments.

## Page character

- Default to a vertical 4:5 canvas.
- Use three panels: one establishing frame, one relationship frame, and one detail frame.
- Every panel must be a crop or scale variation of the same supplied photo.
- Separate panels with clean neutral gutters. Use no torn edges, tape, stamps, film sprockets, or scrapbook ornament.
- Use one quiet background color sampled from the source and one restrained accent line.
- Let the panel sizes create rhythm: large, medium, small. Avoid an equal three-column template.

## Build the sequence

Read the source as a single moment and identify the frame that establishes attention, the relationship between visible subjects or between a subject and its surroundings, and one small detail that changes how the whole scene is understood.

Assign those observations to the three panels. Crops may overlap in content, but each must answer a different visual question. Keep the original orientation unless rotating a detail crop is explicitly requested.

## Caption system

- Add one title and up to three micro-captions.
- Use user-provided text first.
- When authoring text, describe only visible qualities such as light, distance, movement, color, repetition, or direction.
- Do not invent dates, places, dialogue, relationships, names, emotions, or biographical context.
- Keep captions short and subordinate to the panels.

## Fidelity rules

- Preserve all people, faces, hands, objects, architecture, products, and scenery.
- Do not synthesize a new viewpoint or a missing part of a person or object.
- Do not add or remove subjects to make a panel cleaner.
- Do not convert panels into drawings or paintings.
- Natural exposure matching across crops is allowed; all crops should still look like the same photograph.
- Protect source logos and text from corruption. If a crop would cut through important text, choose another crop.

## Quality gate

Confirm that all three panels can be traced to the same source, the reading order is clear without arrows, the largest panel carries the scene, and no caption claims information absent from the photo or user request.

Return the finished image only unless the user asks for the crop rationale.
