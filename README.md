# JoeyBeyond Editorial Photo Skills

一套由杭州珺轶致远科技有限公司独立创作的摄影编辑 Skill，用于“一图百变”及 JoeyBeyond 旗下产品。

- `scene-ledger-poster`：场景档案海报，以主照片、索引规则和事实型元数据建立档案感。
- `chromatic-window-cover`：色窗杂志封面，以摄影窗口、结构性色块和封面层级建立现代感。
- `sequential-memory-sheet`：连续记忆画页，以同一照片的三个真实裁切建立阅读节奏。

三项 Skill 均要求保护人物身份、物体结构、建筑、Logo、原始文字和场景事实，不执行仓库脚本，也不要求保存用户图片。
